# 🛡️ Surveillance (v1.0.1)

A private, offline security recording manager with background CameraX services, live GPS coordinate watermarking, biometric authentication, and auto-cleanup policies.

## 📖 Comprehensive Documentation
👉 For complete feature breakdown and user instructions, see **[APP_FUNCTIONALITY.md](file:///d:/_test/survilliance/APP_FUNCTIONALITY.md)**.

## ✨ Highlights
- **4 Main Tabs:** Home (Active Recording Hub), Files (Categorized Archives), Vault (Encrypted Storage), Settings (Video/Audio/Security Controls).
- **Multi-Mode Recording:** Background HD/4K Video Recording, Low-power stealth Audio capture, and Instant Stealth Photo Capture.
- **GPS Geo-Tagging:** Live latitude/longitude coordinate stamping directly onto footage and EXIF metadata.
- **Biometric Security:** Fingerprint, Face unlock, and 4-digit security PIN protection with private `.vault` encryption.
- **Video Player:** Speed control (0.5x to 2.0x), Picture-in-Picture (PiP), EXIF inspector, filter chips (Today, This Week, This Month, Favorites).
- **Auto-Maintenance:** Automated background cleanup worker for old clips (7 to 60 days) and low storage safety cutoff.
- **Distribution:** 3-dot overflow menu for About, Download APK to public Downloads folder, Share APK via FileProvider, and Developer Feedback.
